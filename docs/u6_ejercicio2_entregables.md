# U6 - Ejercicio 2: entregables priorizados

Este paquete resuelve el ejercicio de gestion de defectos y validacion final con referencia directa al Proyecto Muebles Modernos.

## Orden de entrega recomendado

| Prioridad | Entregable | Archivo | Proposito |
| --- | --- | --- | --- |
| 1 | Reporte de defectos priorizados con trazabilidad | `docs/u6_ejercicio2_reporte_defectos_priorizados.md` | Identificar, clasificar, priorizar, hacer seguimiento y cerrar defectos. |
| 2 | Dashboard de metricas de calidad | `docs/u6_ejercicio2_dashboard_metricas.md` | Visualizar pruebas, estados, prioridades y riesgos. |
| 3 | Informe tecnico de validacion | `docs/u6_ejercicio2_informe_tecnico_validacion.md` | Sintetizar hallazgos, conclusiones y recomendaciones. |

| Evidencia | Archivo |

## Lectura sugerida para sustentacion

1. Abrir primero el reporte de defectos y explicar los P1: DEF-004 y DEF-006.
2. Mostrar el dashboard para justificar con metricas que las pruebas actuales pasan, pero aun hay riesgos residuales.
3. Cerrar con el informe tecnico, destacando que el proyecto esta listo para sustentacion y que las mejoras principales son automatizar E2E real y ampliar pruebas por servicio.
